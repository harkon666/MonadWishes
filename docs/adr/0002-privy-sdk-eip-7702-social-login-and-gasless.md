# 2. Privy SDK for EIP-7702 Social Login & Gasless Transactions

* Status: Accepted
* Date: 2026-08-08

## Context and Problem Statement
Non-Web3 native users participating in birthday gift pools find crypto wallet installation (MetaMask) and gas fee acquisition friction-heavy.

## Decision Drivers
- High conversion for consumer crypto / SocialFi app.
- Rapid integration speed (< 30 minutes) during 8-hour vibe coding hackathon.

## Decision Outcome
Chosen Option: Privy SDK. Provides embedded wallets via Google/Twitter login and Account Abstraction (EIP-7702) gas sponsorship so users can contribute without purchasing MON for gas fees.
