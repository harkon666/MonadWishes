# 3. Dynamic On-Chain SVG NFT Memory Booklet

* Status: Accepted
* Date: 2026-08-08

## Context and Problem Statement
When a birthday vault is claimed, recipients should receive a permanent, emotionally meaningful memory booklet containing greetings and gift statistics.

## Decision Outcome
Chosen Option: 100% Dynamic On-Chain SVG NFT rendered inside `MonadBirthdayNFT.sol`. Eliminates external IPFS dependencies and showcases advanced smart contract execution capabilities to Monad hackathon judges.
